# Cafe Manager PWA

A free installable web app for a small cafe.

## What it does
- Records cash/card sales
- Tracks products and prices
- Tracks inventory and low-stock levels
- Automatically deducts linked inventory after a sale
- Shows daily revenue and order count
- Exports/imports a JSON backup
- Works offline after the first visit

## Easiest free deployment: GitHub Pages
1. Create a free GitHub account and a new public repository.
2. Upload every file and folder from this package.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose “Deploy from a branch.”
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide a public HTTPS address.
7. Send that address to your mom.
8. On iPhone: open it in Safari > Share > Add to Home Screen.
9. On Android: open it in Chrome > menu > Add to Home screen or Install app.

## Important limitation
This version saves data only on that device using browser storage. It is ideal for one main phone or tablet.
Use Settings > Export backup regularly.

For multiple employees or shared live data, the next version needs a cloud database and login system.
